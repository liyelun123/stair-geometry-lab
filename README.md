# 楼梯几何实验室（Stair Geometry Lab）

一个零依赖、可在浏览器直接运行的土木参数化直梯几何实验工具。输入总高度、级数、踏面宽、梯段净宽和顶层平台长度后，实时生成三维外轮廓模型、侧立面图、关键几何参数计算及 A/B 双方案对比。

- **在线体验链接**：https://liyelun123.github.io/stair-geometry-lab/
- **本地运行**：下载后直接用 Chrome / Edge 打开 `index.html`，无需安装依赖或联网。

## 主要功能

- **实时三维外轮廓建模**：支持鼠标拖动旋转、滚轮缩放及键盘方向键微调，可切换尺寸标注。
- **核心几何计算**：实时计算每级高度、梯段踏面数、梯段水平长、含上平台总长、平面占地及鼻口连线倾角。
- **A / B 方案对比**：保存当前参数为对照方案 A，调整参数生成方案 B，直观对比级高、长度与占地变化。
- **展示导出与自动演示**：支持导出带参数与对比数据的 PNG 展示图、JSON 参数文件，以及 30 秒自动演示（展示 16 / 18 / 20 级对比后自动还原）。

## 几何约定与边界说明

- 总高度 $H$：下层完成面到上层完成面的竖向高度（mm）
- 上升次数 $n$：包含进入顶层平台的最后一次上升；梯段踏面数为 $n - 1$
- 每级高度 $h = H / n$，梯段水平长 $L = (n - 1) \times b$，含上平台总长 $= L + p$
- 平面占地 $S = (L + p) \times W / 10^6$（$\text{m}^2$），鼻口连线倾角 $= \arctan(h / b)$
- **适用边界**：模型按外轮廓生成挤出体块，仅用于几何尺寸分析与参数化演示，不代表真实混凝土实体结构，不进行受力、配筋、净空或规范合规性审查。

## 目录结构

- `index.html`：页面结构与参数输入控件
- `style.css`：界面样式与响应式布局
- `geometry.js`：纯几何计算与轮廓点生成模块
- `app.js`：界面联动、三维投影渲染、导出与自动演示逻辑
- `check-geometry.cjs`：几何计算自动核对脚本（有 Node.js 时可运行 `node check-geometry.cjs`）
- `samples/`：界面预览图、导出展示图及示例参数 JSON
